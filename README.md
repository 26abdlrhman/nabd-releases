# نبض — تنزيل تطبيق الوكيل لويندوز

تطبيق إصدار وثائق الطرف الثالث والتأمين الإجباري. هذا المستودع لملفات الإصدار فقط؛ لا يحتوي الكود أو بيانات الوكلاء أو مفاتيح الربط.

[تنزيل مُثبت تطبيق الوكيل لويندوز x64](https://github.com/26abdlrhman/nabd-releases/releases/latest/download/nabd-agent.exe)

1. نزّل الملف وشغّله لإتمام التثبيت على Windows 10 أو Windows 11 بنظام 64 بت.
2. افتح اختصار **Nabd Insurance** من سطح المكتب أو قائمة ابدأ.
3. عند التثبيت على جهاز جديد تظهر تهيئة الحساب لأول مرة. تُحفظ بيانات الجهاز محلياً؛ التثبيت الجديد لا يجلب وثائق جهاز آخر تلقائياً.
4. يفحص التطبيق التحديثات تلقائياً. يُنزّل الإصدار الموقّع ويؤجل الانتقال إذا كان هناك عمل غير محفوظ، ويحتفظ بنسخة احتياطية مشفرة قبل ترقية القاعدة.

لا تحتاج إلى تثبيت Python أو Git. استخدم المُثبت أو الاختصار؛ ملف `nabd-update-windows-x64.exe` مخصص للمحدّث الداخلي ولا يُشغّل يدوياً.

[الإصدار الحالي وملفاته](https://github.com/26abdlrhman/nabd-releases/releases/latest)

التحديث يحافظ على بيانات التثبيت الحالي. نقل قاعدة مشفرة إلى جهاز مختلف يحتاج إجراء نقل مناسب لمفتاحها. برنامج نبض الإدارة يُوزَّع بشكل مستقل؛ رابط التنزيل أعلاه خاص بتطبيق الوكيل.
