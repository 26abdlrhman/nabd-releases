# نبض — تنزيل نسخ Windows

هذه الصفحة مخصصة لتنزيل نسخ Windows (exe) من منظومة نبض.

## التنزيل

| التطبيق | الوصف | التنزيل |
|---------|-------|---------|
| **نبض — الإدارة** | النظام الرئيسي للإدارة والتقارير | [الإصدار الأحدث](../../releases/latest) |
| **تطبيق الوكيل** | تطبيق الطرف الثالث والإجباري للوكلاء | [الإصدار الأحدث](../../releases/latest) |

## طريقة التثبيت

1. حمّل الملف `.exe` من صفحة الإصدارات
2. شغّل الملف مباشرة (بدون تثبيت)
3. سيفتح النظام تلقائياً في المتصفح على `http://localhost:8000`

## ملاحظات

- لا يحتاج البرنامج إلى تثبيت Python
- قاعدة البيانات تُنشأ تلقائياً عند أول تشغيل
- للتحديث: حمّل النسخة الأحدث من نفس الصفحة
